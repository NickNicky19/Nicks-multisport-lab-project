GitHub Pages website, and a prospective paper-ticket system supporting 2–6 legs.

for results. Treat that phrase as the required standard of careful work.

MILESTONE 1 — FULL NBA REFERENCE BASELINE AND CONTROLLED IMPROVEMENTS

Planned joint primitive outputs:
FG2M, FG3M, FTM, REB, AST, TOV, BLK, STL

Derive within each SAME outcome sample:
PTS = 2*FG2M + 3*FG3M + FTM
3PM = FG3M
PR = PTS + REB
RA = REB + AST
PRA = PTS + REB + AST
BLK+STL = BLK + STL
PA = PTS + AST, if included

For DD/TD, count how many of PTS, REB, AST, STL and BLK are at least ten:
DD = 1 if at least two qualify, else 0
TD = 1 if at least three qualify, else 0
Do not count threes or turnovers. Preserve TD <= DD.

of correct joint dependence. Direct sum challengers cannot silently replace the
