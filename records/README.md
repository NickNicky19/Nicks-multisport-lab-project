# Immutable research records

These small create-only receipts are the repository ledger. See
[DURABLE_LEDGER.md](../docs/DURABLE_LEDGER.md) for APIs and correction/recovery
rules. Original bytes and clocks are retained. Commit/push plus independent fresh
remote readback establish Git retention separately from a local write.

The initial eighteen receipts are six historical reconstructed forecasts, six
compact actual archived outcomes and six separate forecast grades selected by
[REFERENCE_PUBLICATION_002.md](../docs/REFERENCE_PUBLICATION_002.md). Every forecast
contains fourteen marginal distributions from the same coherent player-stat law.
They were actually generated on October 20, 2026 for November 24, 2025 events.
The outcome observation clock is the current local archive read. No historical
pregame issuance/availability, future forecast, actual paper ticket, profit or
financial settlement is claimed. No bulk source archive or raw support rows are
retained here. The static export does not include raw ledger envelopes/outcomes.
